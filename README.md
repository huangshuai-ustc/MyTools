# 我的工具箱

"我的工具箱"是一个使用 SwiftUI 编写的本地优先多平台应用。工程目前包含"个人金融""我的股票""换汇记录"和"健康档案"四个工具模块，用于整理银行账户、股票持仓、换汇损耗、就诊与体检历史；工具箱入口已经为后续增加其他个人工具预留了模块位置。

当前版本为本地 MVP 1.3，界面语言为中文，不依赖第三方软件包。

## 平台与工程信息

- iOS / iPadOS 26.0 及以上
- macOS 26.0 及以上
- Xcode 26.0 及以上
- Swift 6.0
- SwiftUI 多平台工程
- Bundle Identifier：`com.fjwyz.PersonalToolBox`
- 实体工程文件：`MyTools.xcodeproj`
- 共享 Scheme：`我的工具箱`
- App 显示名称：`我的工具箱`

工程文件和源码目录继续使用英文名称 `MyTools`，Xcode Scheme 与设备上的 App 名称使用中文。这两套名称是有意区分的，不需要把磁盘目录改成“我的工具箱”。

## 当前功能

### 工具箱首页

- 使用独立工具模块入口组织功能，目前包含“个人金融”“我的股票”“换汇记录”和“健康档案”。
- 显示当前银行数量和未销户银行卡数量。
- 新建但尚未添加银行卡的正常银行仍计入当前银行；没有正常借记卡、没有正常子账户且已有停用迹象的历史银行不计入当前银行。
- 可以在“我的 > 首页功能”中控制每个工具模块是否显示，关闭后的开关和模块图标显示为灰色。
- 后续可以在 `ToolModule` 中继续增加其他工具模块。

### 个人金融

- 个人金融首页按“全部”“境内”“境外”切换，概览统计会同步切换，不再固定显示全部档案。
- 境内银行以银行卡为主要档案载体，境外银行以多个子账户为主要档案载体；境内子账户（例如个人养老金、私人理财）仍可选择性添加。
- 银行列表默认隐藏没有正常借记卡、没有正常子账户且已表现为停用的历史银行；首页会显示隐藏数量，可一键展开，不会删除任何数据。
- 首页展示银行、子账户、借记卡和信用卡数量，并在银行行内展示卡片、子账户和状态摘要。
- 首页支持搜索银行、支行、账户类型、账户号、币种、卡种、持卡人和卡号等信息。
- 银行账户支持以下排序方式：
  - 添加顺序
  - 开户时间从新到旧或从旧到新
  - 名称 A-Z 或 Z-A
  - 境内优先或境外优先
- 银行账户默认按名称 A-Z 排列，浏览页和管理页共用排序偏好。
- iOS 的层级页面会在返回按钮中显示上一层名称，例如“工具箱”“个人金融”“我的”或“银行账户”。
- 境内银行使用绿色“境内”标记，境外银行使用橙色“境外”标记。
- 银行列表可以切换“全部”“境内”“境外”，筛选后继续沿用当前排序方式。
- 账户详情按地区组织信息：境内和境外均为账户信息、子账户、银行卡、登录信息和其他；境外在登录信息之后额外显示地址与汇入汇款资料。
- 银行账户、子账户和银行卡统一从一个“编辑银行档案”入口维护。新增、编辑和删除子账户或银行卡都先进入同一份编辑草稿，点击保存时一次性提交，避免多个重复入口造成数据不同步。
- 普通模式可以查看银行、子账户和银行卡详情；管理员模式只额外解锁整体编辑入口。银行卡完整卡号、CVV、有效期、登录密码和信用卡账单 PDF 继续独立验证后显示。
- 币种选择收起为常用币种，其他已支持币种放在“更多币种”中；旧档案中的币种不会被删除，未来扩展只需在 `CurrencyCode` 的可选配置中增加。
- 信用卡可以在银行卡编辑页添加多份 PDF 信用卡账单，记录账单日期和备注；账单文件保存在本机附件目录，并随加密 `.mytools` 备份导出和恢复。

### 我的股票

- 支持记录 A 股、港股和美股，每只股票保存市场、代码、自定义名称及完整买卖流水。港股代码统一按 5 位数字保存，例如腾讯控股为 `00700`。
- 新增股票时填写首次购买时间、购买股数、每股价格和可选交易费用。
- 股票详情可以继续添加或修改买入、卖出记录；卖出或删除交易时会校验持仓不能小于零。
- 股票详情可以按实际到账记录分红，填写到账日期、分红股数、每股分红、可选预扣税、可选其他费用和备注；税前分红按“分红股数 × 每股分红”自动计算，再扣除税费得到净到账金额。没有分红的股票无需添加记录。
- 当前持仓、累计买入、累计卖出和净投入均由交易流水自动计算；累计净分红由分红流水计算。总盈亏采用“持仓市值 + 累计净分红 - 净投入”，分红不改变持仓股数和净投入。
- A 股使用 CNY、港股使用 HKD、美股使用 USD 分开汇总，不进行隐含汇率换算。
- 每个市场分别显示净投入、当前持仓市值和总盈亏；缺少行情的持仓会标记为待同步，不会按零估值。
- 每只股票在列表中显示其持仓市值占当前市场筛选范围总市值的比例；“全部”按中国银行现汇买入价折算人民币后计算，市场分页以本市场总市值为分母。全部页的 A 股、港股和美股汇总行同时显示各市场占比；总市值为零时显示 `0.00%`，缺少必要行情或汇率时显示“待同步”。
- 股票页面打开时刷新行情，并在页面可见期间每 300 秒自动刷新；同时支持下拉刷新和工具栏手动刷新。
- 正常刷新会把 A 股、港股和美股合并为腾讯证券批量请求，同时使用新浪财经批量校验；每只股票按行情时间选择更新的有效结果，不再让最先返回但时间较旧的缓存值直接胜出。批量结果缺失时，A 股使用上海/深圳证券交易所与东方财富兜底，港股使用东方财富与 Yahoo Finance 兜底，美股使用 Nasdaq 与 Yahoo Finance 兜底。
- 腾讯和新浪的正常路径固定为每 40 只股票最多各一次请求，避免股票数量增加时线性放大连接数。Yahoo Finance 在中国大陆网络可能返回 403，Nasdaq 响应也可能较慢，因此两者不再阻塞正常批量刷新，只在对应市场缺失数据时使用。
- 美股不再猜测东方财富的 105/106/107 市场编号，避免同一代码在不同市场命中错误证券；Nasdaq 数据优先采用常规交易时段口径。
- "全部""A 股""港股""美股"会只显示对应范围的资产汇总，并按中国银行港币、美元现汇买入价提供人民币折算合计。
- "最近刷新"记录本次行情刷新成功完成的时刻，并固定按北京时间显示，不再把某个行情源返回的交易时间当作刷新时间。
- 公开行情可能延迟或临时不可用，App 会保留最后一次成功价格和更新时间，交易决策应以交易所及券商数据为准。
- “我的 > 首页功能”可以关闭任一工具入口并拖动调整首页顺序；设置页与工具箱首页始终使用同一顺序。
- 股票支持按名称 A-Z 或最早购买时间排序。

### 换汇记录

- 保存换汇日期、卖出币种、买入币种、录入价格、卖出数、实际买入数和可选手续费；日期统一按当天 12:00 保存和展示，记录默认按换汇日期降序排列。
- 价格可选择“1 单位卖出币种可买入多少单位买入币种”，或银行牌价常用的“100 单位买入币种需要多少单位卖出币种”口径。
- 实际买入数由用户填写银行最终到账金额；理论买入数由价格和卖出数自动计算，两者的差额才是汇率损耗计算依据。
- 手续费按卖出币种额外支付，页面计算理论买入金额和含手续费实际汇率。
- 每笔换汇把换汇前卖出的本金与手续费、换汇后实际持有的外币都按当前中国银行现汇买入价折算为人民币，以两者差额作为当前汇率损耗。
- 每笔损耗和累计损耗统一显示为人民币，并随中国银行买入价刷新；正数表示亏损并显示为绿色，负数表示盈利并显示为红色且省略负号，左侧同时标识“亏损”“盈利”或“持平”。
- 新增数据统一提供人民币、港币、美元、加拿大元、瑞士法郎、欧元、英镑、日元、新西兰元、新加坡元和泰国铢；前三项固定置顶，其余按货币代码首字母排列。个人金融与换汇记录共用同一份可扩展币种定义。旧档案中的澳元和澳门元仍可读取，但不再作为新增选项。
- 上述外币都由同一次中国银行牌价请求读取；币种牌价暂不可用时，该笔记录会显示为“待同步”，不会按零计算。
- 记录支持新增、编辑和侧滑删除，并随本地档案和 `.mytools` 加密备份保存。
- 记录会以人民币为标准显示方向标签：人民币换外币标记为蓝色"卖出"，外币换人民币标记为紫色"买入"，外币互换标记为"外币兑换"。
- 换汇记录支持按买入或卖出方向筛选、按币种名称或代码搜索，并按月份分组显示；总览始终统计全部记录，不受当前筛选影响。
- 换汇页面顶部提供“中国银行换汇汇率”入口，子页面读取股票和换汇模块共用的牌价缓存，默认在左侧显示 `100 外币 → CNY`，也可切换到 `100 CNY → 外币`；每种币同时显示结汇现汇买入价和购汇现汇卖出价，并可主动刷新。
- 中国银行牌价页提供任意两个内置币种之间的双向换算，编辑任一金额都会自动计算另一金额；卖出外币采用现汇买入价，买入外币采用现汇卖出价，外币互换经人民币交叉计算。
- 累计亏损显示“人民币总损耗”及绿色金额，累计盈利显示“人民币总盈利”及红色金额。

### 健康档案

- 以一次就诊、购药或体检为一条事件。门诊、急诊和住院保存日期、医院、科室、可选医生、主诉、初步诊断、治疗建议和备注；“药房购药”只要求日期、药房和至少一项药品，可选填写用药原因，并复用费用、支付、附件与标签能力。
- 健康档案首页提供医院资料库，独立保存医院名称以及可留空的一级/二级/三级、甲等/乙等/丙等、综合医院/专科医院三个维度。就诊时可以选择已有医院；直接输入的新医院会在保存就诊时自动收录，资料库内编辑医院会同步更新同名历史记录，删除医院资料不会删除健康档案。
- 可以从任意门诊、急诊或住院详情新增多条关联复诊，或新增关联药房购药；复诊会预填常用就诊信息，关联购药复用独立购药的药房、药品、费用与附件能力，并归属到原就诊。
- 健康档案首页不再逐条展开复诊或关联购药，只在原就诊行显示数量；进入原就诊详情后按日期查看全部关联记录。搜索命中关联记录时仍会保留原就诊上下文。
- 体检记录保存体检机构、套餐、报告日期、主检结论、健康建议和报告附件；同一次体检可添加多个检查批次，分别记录补检日期、完成项目与备注，并可整理报告中的关注项、结果和建议。
- 每条就诊、复诊、购药或体检记录的本次费用自动等于其费用项目合计，无需手动填写总费用；费用项目金额和医保报销支持数字、`+ - × ÷` 与括号。
- 原就诊详情的总费用自动等于原就诊费用项目合计、全部关联复诊和关联购药的费用之和，并分别展示各项费用；年度统计仍按每次记录的实际日期统计，不会重复计算。
- 选择“自费”时本次项目合计全部计入自费，选择“医保”时全部计入医保支付；选择“医保后自费”时，医保支付和自费任意填写一项，另一项会按差额自动计算。
- 健康首页默认显示当前年份的总医疗费用、医保支付和自费，可切换其他年份；就诊历史按年份倒序分组。
- 支持搜索医院、药房、体检机构、套餐、补检项目、关注项、科室、医生、主诉、诊断、治疗建议、费用项目、附件类型和标签，并可以直接点选标签筛选记录。标签是可选的跨记录自定义归类，例如“年度体检”“膝伤”“长期用药”或“待复查”，不替代科室和诊断。
- 每项药品、检查或其他发票项目独立保存项目名称、数量、单位、金额和备注；项目金额支持四则运算，项目合计会实时同步为本次总费用。
- 每次就诊或体检可以添加多张照片或从“文件”导入图片、PDF，并把附件分类为发票、病历、检验报告、体检报告、CT、MRI、X 光、化验单、扫描件或其他。
- iOS 使用系统 Quick Look 在 App 内预览附件，macOS 使用系统默认查看器打开。
- 门诊、急诊、住院、药房购药和体检分别使用蓝色、红色、紫色、绿色和薄荷色标签；健康详情中的文字数据支持长按直接复制，并显示复制提示。
- 普通模式可以浏览就诊详情；新增、编辑、侧滑删除继续使用全局管理员模式，认证过期后不会清空未保存的表单。
- 复诊费用按实际复诊日期计入年度统计；删除单条复诊不影响原就诊，删除原就诊会同时删除其全部复诊和关联附件。
- 附件正文保存在应用支持目录，日常 JSON 档案只保存元数据；导出加密 `.mytools` 备份时附件正文会一同打包。

### 境内银行账户

- 银行层保存银行名称、支行名称、备注名称、状态、开户时间和备注；状态固定为“正常”“异常”或“已销户”。
- 境内银行可以不添加子账户，也可以在同一家银行下添加多个子账户。
- 每个子账户独立保存账户名称、账户类型、账户号、正常/异常/销户状态和一个或多个币种，币种通过复选框选择。
- 境内常用账户类型包括个人养老金账户、社保账户、公积金账户、外汇账户和储蓄账户；选择“其他账户”后可以填写银行实际使用的自定义类型。
- 账户名称用于区分同类型的多个账户。境内子账户保存时必须填写名称、账户号并至少选择一个币种，新增时默认选择人民币 CNY。

### 境外银行账户

- 银行层保存银行名称、支行名称、SWIFT 和 IBAN；SWIFT 与 IBAN 统一在“汇入汇款资料”中维护，不再重复录入。
- SWIFT 与 IBAN 由同一家银行下的多个账户共享。
- 一家境外银行可以添加多个子账户，同一种账户类型也可以重复添加。
- 每个子账户独立保存：
  - 账户类型
  - 账户名称
  - 账户号
  - 一个或多个币种
  - 正常、异常或已销户状态
- 境外银行的子账户保存时必须填写账户名称、账户号并至少选择一个币种。
- 当前账户类型包括储蓄账户、往来账户、定期存款账户、外汇账户、投资账户和其他账户；“其他账户”支持填写自定义类型。
- 境内和境外银行详情统一按账户信息、子账户、银行卡、登录信息和其他信息排列；境外银行在登录信息之后额外显示地址与汇入汇款资料。
- 银行登录信息由固定的绑定手机号、登录账号、登录密码和可选的附加字段组成。附加字段可按银行原文自定义名称、内容及是否需要遮罩，例如“自在理财账户号码”或“电话银行密码”；敏感字段在详情页中默认遮罩并可独立验证查看。

### 银行卡

- 银行卡通过所属银行账户关联，不在银行卡档案中重复保存银行名称和支行名称。
- 每张银行卡可以标记为借记卡或信用卡，并可以另填“Visa 白金卡”等可选卡片名称。
- 每张银行卡可以多选银联、Visa、Mastercard、JCB、美国运通、大来卡和 Discover 等发卡组织，列表与详情以标签展示。
- 保存卡片名称、卡片类型、发卡组织、持卡人、完整卡号、CVV、有效期、开卡时间、币种和状态。有效期按国际惯例显示为 `MM/YYYY`（年月）或 `MM/DD/YYYY`（年月日）。
- 每张银行卡必须选择至少一个币种；境内新卡默认选择人民币 CNY。
- 银行账户下的银行卡默认按卡片名称 A-Z 排列；可以按名称、开卡时间、借记卡/信用卡优先或状态排序，也可以只查看借记卡或信用卡。
- 境外银行卡的持卡人输入使用英文大写键盘，支持 `HUANG SHUAI` 这类带空格的拼音姓名。
- 有效期支持“年月”和“年月日”两种精度，默认使用年月。
- 卡片状态包括：
  - 正常：绿色
  - 异常：橙色
  - 已销户：红色
- 普通模式可以进入银行卡详情，默认只显示卡号尾号，并隐藏完整卡号、CVV 和有效期；通过 Face ID、Touch ID 或管理员密码后仅在当前详情页显示，不会进入管理员编辑模式。
- 银行、银行卡和子账户的已填写信息支持长按直接复制，并显示复制提示；境内和境外子账户在普通模式下也能进入只读详情。

### 管理员模式

- 首次使用时设置至少 6 位的管理员密码。
- 后续可以使用管理员密码，或通过 Face ID、Touch ID、设备密码验证进入管理员模式。
- App 进入后台时会自动退出管理员模式。
- 管理员可以新增、编辑和删除银行账户、股票交易、换汇记录、健康档案和医院资料，以及导出、导入备份。
- 管理员可以在境内银行下管理个人养老金、私人理财等可选子账户。
- 删除银行账户会同时删除与其关联的银行卡。

普通模式允许只读查看账户、境内/境外子账户、银行卡、股票和健康档案详情；登录密码与银行卡完整卡号、CVV、有效期默认遮罩，独立验证身份后才能显示，且不会因此进入管理员模式。管理员模式只额外负责新增、编辑、删除和备份操作。

独立查看敏感信息时，验证页面会等待呈现动画结束后再主动调起 Face ID / Touch ID，并锁定重复点击、显示验证进度，避免多个系统认证请求相互冲突而出现界面无响应。

## 数据存储与安全

### 当前本地存储

当前银行账户、银行卡、股票、换汇记录、健康档案元数据和医院资料库使用 JSON 编码后，原子写入 App 沙盒的 `Application Support/MyTools/local-vault.json`。健康附件和信用卡账单 PDF 单独保存在 Application Support 附件目录。

日常修改会先在主线程生成值类型快照，再交给独立串行队列完成 JSON 编码和原子写盘；连续发生的修改会合并为最后一份待写快照，避免保存和行情刷新阻塞界面。App 进入后台时会等待已排队写入完成。导出/导入备份时，附件读取、PBKDF2 密码派生、AES-GCM 加解密和附件恢复同样在后台执行，密码页会显示处理状态并阻止重复提交。

启动时会先完成 SwiftUI 首帧，再在后台并行读取本地档案与汇率偏好；首页只等待独立档案文件，汇率缓存完成后再单独应用，避免 `UserDefaults` 冷启动阻塞全部界面。日志会分别输出文件读取、JSON 解码、旧数据迁移和总耗时。加载期间使用轻量系统进度层避免短暂显示错误的零统计。已经存在新版本地档案时，管理员认证不会再次重复解码和保存全部数据。

需要注意：

- 当前完整本地档案没有进行应用层加密，卡号和 CVV 也包含在本地 JSON 文件中；iOS 文件采用“设备首次解锁后可访问”的系统文件保护。
- App 沙盒提供系统级的应用隔离，但这不等同于使用独立密钥加密数据文件。
- 管理员密码经过 SHA-256 计算后保存在 `UserDefaults`，当前没有使用独立盐值。
- `SecureStore` 仍保留旧版 `UserDefaults` JSON、AES-GCM 数据和 Keychain 密钥的读取逻辑，用于兼容迁移旧数据；`local-vault-data` 只有在独立文件成功写入后才会删除。
- 卸载 App 通常会删除 App 沙盒和其中的本地档案。重新安装前应先导出备份。

应用还会保存一份经过脱敏的兼容数据，其中银行卡只保留卡号末四位、CVV 为空，境外账户号与非敏感附加登录字段只保留末四位，SWIFT、IBAN、登录密码及敏感附加登录字段为空，股票交易和分红流水为空。

### 文件备份

管理员可以在“我的”页面导出或导入 `.mytools` 备份文件。

- 导出密码至少为 8 位。
- 备份使用 PBKDF2-HMAC-SHA256 派生 256 位密钥，迭代次数为 210,000 次。
- 档案内容使用 AES-GCM 加密，并使用随机盐值。
- 备份可以通过系统文件选择器保存到“文件”App、本地文件夹或 iCloud Drive。
- 导出的默认文件名使用本地日期和时间，格式为 `yyyyMMddHHmm.mytools`，例如 `202607231029.mytools`。
- 保存到 iCloud Drive 只是在多台设备之间同步备份文件，不是 App 数据的自动实时同步。
- 导入备份会替换当前全部银行账户、银行卡、股票、换汇记录、健康档案和医院资料库；健康附件和信用卡账单 PDF 也会从加密备份恢复。
- 新导出的备份格式版本为 7；当前版本仍可以导入版本 1 至 6 备份。
- 备份界面默认填入 `1.2.3.4.`；留空也会使用这个默认密码。改用自定义密码后，App 不会保存该密码，丢失后无法解密备份。

## 打开与运行

1. 在 Xcode 中打开 `MyTools.xcodeproj`，不要查找 `我的工具箱.xcodeproj`。
2. 在顶部 Scheme 中选择“我的工具箱”。
3. 在 Target 的 Signing & Capabilities 中选择自己的开发团队。
4. 如果 Bundle Identifier 与已有 App 冲突，请改成自己的唯一标识符。
5. 选择 iPhone、iPad 或 My Mac 后运行。

工程以 iOS、iPadOS 和 macOS 26 系列及以上系统为主要运行环境，需要使用 Xcode 26 或更高版本。连接真机时，Xcode 还必须包含对应设备系统版本的开发支持；例如设备运行 iOS 27 Beta 时，需要使用明确支持该 Beta 版本的 Xcode 27 Beta，否则可能出现 Developer Disk Image 无法挂载或缺少对应 variant 的错误。

## 基本使用流程

1. 打开“我的”页面并进入管理员模式。
2. 首次进入时设置管理员密码。
3. 从“个人金融”页面点编辑按钮，验证管理员身份后创建境内或境外银行档案。
4. 进入银行详情后点编辑，在同一个编辑页面维护银行卡、子账户、登录信息、地址和汇款资料。
5. 信用卡可以在同一编辑页面添加 PDF 信用卡账单；根据需要在境内或境外银行下添加子账户。
6. 返回“工具箱”中的“个人金融”，浏览、搜索和排序档案。
7. 在“我的 > 首页功能”中控制工具模块是否显示。
8. 数据录入完成后，在“我的”页面导出 `.mytools` 加密备份并保存到“文件”App。
9. 从工具箱进入“我的股票”，添加股票及首次买入信息，后续在股票详情中维护买卖流水。
10. 从工具箱进入“健康档案”，验证管理员身份后记录就诊、复诊、药房购药、费用项目、标签和附件；从健康首页进入医院资料库维护常用医院。

## 重构约束与扩展方式

本轮个人金融重构保留现有银行、银行卡、子账户字段和用户偏好键，并为银行卡增加可选信用卡账单字段；旧本地档案与旧 `.mytools` 文件仍可读取。备份格式版本升至 7，以确保旧版本不会误读后重新导出而丢失信用卡账单附件。

后续新增工具时，建议把完整功能放在 `Features/<功能名>/`，把入口元数据加入 `ToolModule`，把跨模块偏好放在 `Settings/`，只把真正通用的组件放入 `Shared/`。这样首页无需再次承担业务逻辑，现有个人金融与股票代码也不会和新模块相互耦合。

## 旧数据兼容

模型解码保留了以下兼容处理：

- 缺少地区字段的旧账户会根据账户号、SWIFT 和 IBAN 推断境内或境外。
- 旧版境内银行层的账户类型和币种会迁移成一个独立境内子账户。
- 旧版境外账户类型集合会迁移成多个独立境外子账户。
- 旧版子账户中的 IBAN 会迁移到银行层共享字段。
- 旧版“收款 SWIFT Code”会在银行层 SWIFT 为空时自动迁移到统一的 SWIFT 字段；旧的自由文本银行状态会归一为三种固定状态。
- 旧银行卡和子账户缺少状态时默认设为“正常”，银行卡缺少有效期精度时默认设为“年月”。
- 旧银行卡或境外账户缺少币种时仍可读取，后续编辑时需要补选币种。
- 旧银行卡没有信用卡账单字段时按空账单列表读取，不影响原有卡片；新账单 PDF 会随版本 7 备份恢复。
- 旧版档案和版本 1 备份缺少股票字段时会按空股票列表读取，不影响原有银行数据。
- 旧股票档案缺少分红字段时会按空分红列表读取；已有的旧分红记录仍保留原税前总额，后续编辑时可以补充对应的分红股数和每股分红。
- 版本 1、2、3 备份缺少健康档案字段时会按空就诊列表读取，不影响原有数据；旧健康档案中的处方药会迁移为费用项目，原服药说明保留在备注中。旧版手动填写但尚未体现在费用项目中的总费用会迁移为“历史费用汇总”或“历史费用差额”项目；旧就诊记录缺少复诊关联字段时仍按普通就诊读取。新增的体检详情为可选字段，旧档案无需迁移即可读取。首次读取缺少医院资料库的旧档案时，会按医院名称合并历史就诊并生成资料库，药房购药不会进入医院资料库。

## 当前限制与后续方向

- 尚未实现 CloudKit 或 iCloud 自动同步。
- 当前股票行情依赖交易所和第三方公开接口，不提供交易所级低延迟保证；iTick 等需要 Token 或实时行情授权的服务尚未接入，后续可以作为可配置的授权数据源；分红需要按券商实际到账手动录入，暂不自动同步分红、拆股或税费调整；美元资产只按中国银行买入价做展示折算。
- 尚未实现本地档案的应用层加密，当前只有手动导出的备份文件经过密码加密。
- 登录密码以及银行卡完整卡号、CVV 和有效期默认遮罩；独立身份验证只临时显示当前详情页的敏感信息。境内和境外子账户号属于普通只读详情信息，可长按直接复制。
- 当前提供“个人金融”“我的股票”“换汇记录”和“健康档案”模块，血压、血糖、BMI、心率等健康指标尚未加入。
- 工程当前没有独立的自动化测试 Target。

在完成本地加密存储、敏感字段访问控制和自动化测试前，不应把当前 MVP 视为面向其他用户发布的高安全级金融密码库。
