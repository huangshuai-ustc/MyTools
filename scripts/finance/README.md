# 银行备份转换

将只含旧银行模型的 `.mytools` 1.0 备份转换为当前金融机构 schema 4。

```sh
scripts/finance/convert-bank-backup.sh 输入.mytools 新文件.mytools
```

运行时提示输入原备份密码；输出沿用该密码。密码不写入脚本、参数或文件。需要 macOS 和 Xcode Swift 工具链。

原文件只读，输出必须为不存在的新路径；不支持覆盖或原地转换。不产生明文备份文件。只转换金融模块顶层 `accounts`、`cards`，其他模块、模块选择、标签和模板原样保留。包含新 profile/provider 或已转换机构的输入拒绝转换。

银行子账户经当前模型映射，保留 ID、境内外分类、名称、类型、币种、状态、开户日期、网点、地址、汇款资料、登录字段和银行卡主次卡号。卡片原始 JSON 保留未知字段与内嵌账单附件。

输出前使用工程实际金融模型解码、关联校验、重新加密和解密回读，并比较原文件未变化。该脚本验证不等于界面导入验证；应用需要包含金融隔离模块的备份恢复修复。

# 券商操作回归检查

运行 `zsh scripts/finance/check-brokerage.sh`。它编译真实金融领域模型，验证券商账户删除、重复删除、入金及登录关联清理、入金资料删除和序列化往返；只使用内存中的虚构资料，不读取或修改用户存档。
