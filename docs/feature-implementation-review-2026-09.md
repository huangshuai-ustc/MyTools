# MyTools 功能实现审查

审查日期：2026-09-13。依据当前工作树源码、Xcode 工程和测试；未提交的业务改动未回滚。

## 结论

九个模块均有可运行的业务实现：金融账户、股票、换汇、健康、美食、保密资料、证照、账单和体彩开奖。Store、Domain 规则、外部 Provider、OCR、地图、附件、备份和 CloudKit 已形成较完整的功能链。iOS 26.5 Simulator 与 macOS arm64 产品构建通过，完整 iOS 测试执行通过。

当前实现的明确边界是：敏感详情使用 LocalAuthentication 临时揭示，项目没有应用自有管理员密码或管理员会话；附件只有系统文件保护，没有应用层加密；公开数据依赖第三方服务，可能延迟或不可用。持仓总价值走势已重做为按真实日期对齐的多系列图表，支持市场合计与按股票分别查看，并支持各时间范围拖动选点。

## 功能评价

| 范围 | 判断 | 依据与边界 |
| --- | --- | --- |
| 业务记录 | 较完整 | 各模块 Store 提供增删改、规范化、筛选和生命周期；数据集中在 `VaultData`。 |
| 敏感查看 | 已实现 | `AuthManager` 调用设备密码/生物识别，仅影响当前详情显示。 |
| 本地安全 | 基础完整 | Vault 为 AES-GCM 2.0，Keychain 保存本机密钥；附件仍是独立未加密文件。 |
| 备份恢复 | 已实现 | `.mytools` 使用 PBKDF2-HMAC-SHA256 + AES-GCM 1.0，按编译且可见模块裁剪，附件随载荷恢复。 |
| CloudKit | 设计完整 | 记录级增量、显式实体白名单、CKAsset、删除 tombstone 和账户变化均有实现；仍需真实 Apple 账户验收。 |
| OCR/地图/导入 | 丰富 | Vision OCR、PDF/图片、MapKit、微信 XLSX、支付宝 CSV、大众点评 WebKit 导入均有实现；第三方页面变更是外部风险。 |
| 行情/图表 | 深入 | 多 Provider、交易日历、缓存、技术指标、盘前盘后和组合历史均已实现；公共数据质量取决于来源。 |

## 本轮修复

- 9 个页面的 `.searchable` 已按平台区分：iOS 使用 `.navigationBarDrawer`，macOS 使用默认 placement。
- 测试中的 `HealthStore`、`DocumentsStore` 和 `StockPortfolioEditor` 初始化调用已与当前 API 对齐。
- 从 Xcode 工程移除已删除的 `SensitiveAccessView.swift` 引用。
- 组合历史使用 Decimal 保存持仓价值，日期归一化复用市场时区日历。
- 组合历史缓存指纹使用排序后的 JSON 输入和 SHA-256，跨进程稳定。
- 持仓总价值走势改用真实日期作为 X 轴，统一顶部摘要高度，分时/五日/日K/周K/月K/季K/年K 均支持最近时间点选取；不同市场系列与股票市场标签颜色一致，人民币合计使用独立强调色。
- 选择具体市场后默认包含该市场全部持仓；打开“按股票分别查看”即可多选股票，每条股票曲线使用稳定的独立颜色。
- README、AGENTS、Info.plist 和备份提示已统一为当前设备身份验证语义。

## 仍需关注

1. 附件未做应用层加密。证照、医疗、银行卡账单和秘密附件的保护依赖沙盒与系统文件保护；若威胁模型要求离线文件不可读，需要设计加密附件格式和迁移。
2. 公开行情、汇率、体育赛果和大众点评导入依赖网络或网页结构；继续保留缓存、超时、部分成功和错误状态。
3. CloudKit、后台刷新、定位、相机和文件导入需要在真实设备与签名环境验证；Simulator 不能代表权限、Keychain、后台和 Apple 账户行为。
4. 组合历史仍建议补充专门的 Decimal、缓存重启命中、多市场时区和跨日持仓测试；新图表还应补充选点与多系列日期对齐测试。
