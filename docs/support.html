常见问题

数据保存在哪里？

方寸优先在本机保存业务档案。你可以在“我的”中导出加密备份；开启 iCloud 后，支持同步的数据可在同一 Apple 账户的设备间同步。

忘记备份密码怎么办？

备份密码由你单独设置，方寸不会保存。遗失密码后无法解密对应备份，请妥善保管。

为什么行情暂时没有更新？

公开行情可能延迟、缺失或暂时不可用。请检查网络、交易时段和数据源状态，并尝试手动刷新；业务记录不会因行情失败而被删除。

如何查看银行卡、密码或证照中的敏感信息？

在详情页点击敏感字段，使用设备密码、Face ID 或 Touch ID 临时验证。方寸没有独立的管理员密码。

使用帮助

  • 在“我的 > 首页功能”中显示、隐藏或调整模块顺序。
  • 股票页支持持仓、看盘、分时与 K 线图表、组合走势、分红和盈亏提醒。
  • 账单、健康档案、美食地图、证照和保密资料支持搜索、标签与附件。
  • 合伙记账默认关闭，可手动开启后记录成员注资、美股交易、股息和清账。

问题反馈

请通过 GitHub Issues 提交问题。请附上设备型号、系统版本、App 版本、所在模块、复现步骤和发生时间。请先遮盖卡号、医疗信息、密钥、账本和其他敏感内容。

方寸不提供电话客服；公开 Issue 适合反馈可复现的问题，敏感资料请勿直接上传。
